这批素材的用途

这个页面怎么用

1. 配好连接。右上角「连接设置」填入你自己的 BytePlus ModelArk API Key，并选好模型档位（Seedance 2.5 / 2.0-fast / 2.0-mini，也可以手填别的 Model ID）。第一次用建议先点「测试连接」，能列出模型就说明 Key 可用。但「模型清单里有」不等于「已开通」——实测 2.0 标准版就在清单里，调用却返 404 ModelNotOpen，要先到控制台开通。切换档位时底部控制台会按该档能力自动收敛：不支持的字段变灰、不会发给上游，取值受限的字段（如输出格式）只列该档认的选项。

2. 接口地址从哪来。浏览器不允许网页直接调上游接口（上游未开放跨域），所以请求必须经一层转发。线上地址（如 https://apivmorai.com/seedance/）已由本站服务器转发，打开即用、无需任何设置；本机自用则在本文件所在目录执行 node proxy.mjs，再打开 http://127.0.0.1:8790/，接口地址会自动填成本机转发地址。

3. 加素材。图片可选本地文件或贴直链（本地图片转 Base64 随请求发出，单张 <30MB、整个请求体 ≤64MB）。视频与音频也可以直接选本地文件——但上游那一栏只收公网直链或 asset://，所以页面会先把文件传到中转收件箱（本机为 proxy.mjs，线上为本站服务器），拿到一条临时直链再交给上游，约 2 小时后自动删除，删除后这条任务就再也不能重跑。也可以跳过上传、直接贴你自己图床 / OSS 的直链。官方数量与时长上限：2.5 参考图 ≤30 / 参考视频 ≤10 段且总时长 ≤30 秒 / 参考音频 ≤10 段且总时长 ≤30 秒；2.0 系列为图 ≤9 / 视频 ≤3 / 音频 ≤3，总时长 ≤15 秒。单条参考素材 2~30 秒、宽高比 0.4~2.5，选文件时页面会先读时长与尺寸预检，超限当场拦下（上游会直接拒）。本机用 proxy.mjs 时，收件箱里的文件只有你自己电脑能访问，上游拉不到这条地址——参考视频/音频要真正出片，必须用线上地址或测试服地址打开本页。

4. 参数与官方字段的对应。以下每一条都有实测支撑（见 §4c）。分辨率 resolution（2.5 = 480p/720p/1080p；2.0 系列 = 480p/720p，实测给 mini/fast 发 1080p 直接被拒，两档都没有 4K）、画幅 ratio、时长 duration（2.5 = 4~30 秒或 -1 智能；2.0 系列 = 4~15 秒或 -1，实测 16 与 30 被拒）、任务类型 omnireference_tasktype（只给 2.5 下发：上游对该字段不做取值校验，无法证明它对 2.0 生效，不赌——但参考图 / 参考视频照样能传，官方矩阵「全模态参考」在 2.0 三档全支持）、声音 generate_audio（三档都发，实测给 mini 发 false 回显就是 false）、格式 output_format（三档都发，但取值按档位收敛：2.5 可选 mp4/mov，2.0 只认 mp4）、水印 watermark、尾帧 return_last_frame（实测上游会做类型校验，说明字段真被解析）、种子 seed。上游硬约束：首帧/尾帧、视频编辑、视频延长三类任务的画幅必须「智能」，视频编辑的时长必须「智能」——页面选到时会自动纠正并提示。

4a. 三档怎么选。要 1080p、时长 15~30 秒、要 mov 输出、或者要用「视频编辑 / 视频延长」→ 只能 2.5。只要 720p 以内、时长 ≤15 秒，想省成本 → 2.0-mini / 2.0-fast（两者能力实测一致，差别在速度与报价）。参考素材上限也随档位变：2.5 图 ≤30 / 视频 ≤10 / 音频 ≤10（总时长 ≤30 秒），2.0 系列图 ≤9 / 视频 ≤3 / 音频 ≤3（总时长 ≤15 秒）——切档时已经加进去的素材如果超了该档上限，生成前会被拦下，请删掉多余的。⚠️ 还有一个坑：2.0 标准版（dreamina-seedance-2-0-260128）会出现在 /models 清单里，但实测直接调用返 404 ModelNotOpen（账户未开通）——「清单里有」不等于「能调用」，所以没把它做成预设；你要用就先到控制台开通，再用「其他」手填。

4b. 没放上去的两个。体验中心截图里的「生成数量（1 videos）」与「样片模式（Draft mode）」在 Ark 接口参数表里找不到对应字段——按「零售端有 ≠ API 有」的纪律，没依据就不放入口，以免你勾了以为生效、实际被上游静默忽略。

4c. 实测记录与仍未证实项。已用真实 Key 经本页同一条中转链路跑过（三个 Model ID 均能建任务并出片，成片回包带可下载直链）：已证实——2.0-mini/fast 只到 720p（发 1080p 返 400）、时长 ≤15 秒（16/30 返 400）、generate_audio 在 2.0 也生效（发 false 回显 false）、output_format 在 2.0 只认 mp4（发 mov 返 400）、2.5 选 mov 确实输出 .mov、return_last_frame 与 seed 可被接受、单条参考视频超 15 秒会被上游拒（它先拉取、再探时长）。仍未证实，页面不赌——① omnireference_tasktype 的生效性：上游连非法取值都返 200（2.5 与 2.0 都是），不做校验，因此只能按官方参数表只对 2.5 下发，且“选了就一定按该类型跑”这句话页面不敢打包；② seed 能否真复现同一结果（需同种子跑两次比对）；③ 图≤9 / 视频≤3 / 音频≤3 这组素材数量上限仍按国内站官方矩阵，未逐条实测；④ 国际站与国内站参数集是否逐字段同构也无书面确认。

5. 异步任务。一条片子通常要 1～5 分钟，页面自动轮询；刷新页面不会重复提交（不会重复计费）。成片地址由上游提供，约 24 小时过期、有下载次数上限，请立刻下载保存。

密钥安全：API Key 只存在你自己浏览器的本地存储里（不勾选「记住」则关掉标签页即清空）。请求里的密钥随转发直达上游：本机模式下只经过你自己电脑上的脚本；线上模式会经过本站服务器做一次转发（服务器不记录密钥、不落请求头日志、不存副本）。公用电脑上请不要勾选「记住」。
